## Privacy first

Recording, transcription, and speaker names all happen on your
computer.

- **Your audio never leaves.** Recordings and transcripts stay in a
  folder you choose.
- **Locked to you.** Keys and voice profiles are encrypted on your
  computer.
- **HIPAA and PHI ready.** Daisy can keep protected health information
  on your device. [HIPAA & PHI guide →](https://www.daisylocal.app/help/hipaa)
- **Your choice to share.** Transcript text goes out only if you pick a
  cloud AI or send it somewhere yourself.
- **Your phone, your computer.** Phone recordings travel only to your
  own computer, over your own network.

---

## Why Daisy

- **Private by design.** Your meetings stay on your computer. Nothing is
  sent to us, ever.
- **Private AI.** Transcripts, summaries, and answers are made on your
  own device. No key, no cloud.
- **No bot in your call.** Daisy records Zoom, Meet, Teams, or any call
  quietly from your computer. Nobody else listens in.
- **Private voice profiles.** Name a voice once and Daisy remembers it,
  encrypted and kept on your computer.
- **Private from phone to desk.** Meetings you record on iPhone or iPad
  travel only to your own computer.
- **You decide what's shared.** Keep everything on your device, or
  choose a cloud AI when you want one.

## How it's built

Everything runs on your machine; each claim maps to a crate you can read:

```
┌─ Your machine ──────────────────────────────────────────────────────────┐
│                                                                         │
│          ┌──────────────────────┐    ┌──────────────────────┐           │
│          │ Mic                  │    │ System audio         │           │
│          │ your voice           │    │ your speakers' output│           │
│          └──────────┬───────────┘    └──────────┬───────────┘           │
│                     └─────────────┬─────────────┘                       │
│                                   ▼                                     │
│          ┌──────────────────────────────────────────────────┐           │
│          │ Echo cancellation — WebRTC AEC3       crates/aec │           │
│          └────────────────────────┬─────────────────────────┘           │
│                                   ▼                                     │
│          ┌──────────────────────────────────────────────────┐           │
│          │ On-device transcription — live captions          │           │
│          │ Nemotron (Win/Linux) · SpeechAnalyzer (macOS)    │           │
│          │                           crates/providers-local │           │
│          └────────────────────────┬─────────────────────────┘           │
│                                   ▼                                     │
│          ┌──────────────────────────────────────────────────┐           │
│          │ Who said what — diarization   crates/voiceprints │           │
│          └────────────────────────┬─────────────────────────┘           │
│                                   ▼                                     │
│          ┌──────────────────────────────────────────────────┐           │
│          │ Transcript cleanup · dedup     crates/transcript │           │
│          └────────────────────────┬─────────────────────────┘           │
│                                   ▼                                     │
│          ┌──────────────────────────────────────────────────┐           │
│          │ Summary · Q&A · workflows       crates/summarize │           │
│          │ Built-in AI — Gemma 4 E4B on    crates/daisy-llm │           │
│          │ llama.cpp (Metal / Vulkan)                       │           │
│          └──────────────────────────────────────────────────┘           │
│                                                                         │
│          ┌─ On disk — your folder ──────────────────────────┐           │
│          │ audio · transcript · summary · notes · search    │           │
│          └──────────────────────────────────────────────────┘           │
│          ┌─ Encrypted vault — Argon2id + AES-256-GCM ───────┐           │
│          │ API keys · voiceprints              crates/vault │           │
│          └──────────────────────────────────────────────────┘           │
│          ┌─ Mobile Sync — your network only ────────────────┐           │
│          │ paired phone ──▶ this desktop, TLS + LAN / BLE   │           │
│          │ recordings in, pipeline here   crates/ble · sync │           │
│          └──────────────────────────────────────────────────┘           │
│                                                                         │
└───────────────────────────────────┬─────────────────────────────────────┘
                                    ┆  transcript text only — never audio
                                    ┆  optional · your key · off by default
                                    ▼
                ┌─ Your chosen LLM ────────────────────┐
                │ cloud with your key — or fully local │
                └──────────────────────────────────────┘
```


The only recording data that can leave your computer is transcript text, and only
if you pick a cloud AI. Audio never does. Read the
**[security & threat model](docs/SECURITY.md)** for the details.

## Read the source, pay for the build

This repository holds the **desktop app** (macOS, Windows, Linux) and
is **source-visible**, so you can verify that audio never leaves your
machine. Daisy for iPhone and iPad is closed source. Issues welcome;
pull requests are not accepted (see [CONTRIBUTING.md](CONTRIBUTING.md)).

Build it yourself ([`docs/BUILDING.md`](docs/BUILDING.md)):

```bash
bash scripts/setup-dev.sh                 # apt deps + rustup + node + pnpm
bash scripts/download-nemotron.sh         # bundled nemotron ASR model (win/linux)
bash scripts/download-nemotron3-diar.sh   # live speaker-name model
bash scripts/download-embeddings.sh       # Q&A embedding model
bash scripts/download-voiceprints.sh      # speaker-recognition models
bash scripts/stage-daisy-llm.sh           # built-in AI worker (sidecar)

pnpm --dir apps/frontend install --frozen-lockfile
pnpm --dir apps/frontend build
cargo build --release -p tauri-app --features custom-protocol
./target/release/daisy-app
```

The paid product is the signed, notarized, auto-updating build at
[daisylocal.app](https://www.daisylocal.app). Self-builds are free for
personal, non-commercial use.

## Why Daisy exists

Daisy was originally built to help our hard-of-hearing child take better
notes in first year — and it kind of took off from there. Something that
used to be genuinely hard suddenly became achievable, as with many
things AI. Privacy mattered as much as making it work well —
and the final transcripts are great. But mostly, Daisy is out here to
help people.
